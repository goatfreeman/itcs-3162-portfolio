# Notebook files

These are copies of the four notebooks supplied for the portfolio redesign.

- Saved cell outputs were removed. Some outputs contained copied dataset rows, charts, or large rendered trees. The website uses selected chart images extracted separately into `assets/charts/`.
- Google Drive file paths were normalized to `data/<filename>` so no personal Drive path is exposed. The referenced CSV files are not included.
- To rerun, obtain the CSVs from their original source, verify license/redistribution terms, place them in the repository's `data/` directory, and run the notebook in Jupyter or Google Colab.
- Notebooks preserve the original analysis approach; the case-study pages describe limitations where those choices affect interpretation.

The cleaned copies are not a substitute for reviewing the source data or reproducing each reported result.
